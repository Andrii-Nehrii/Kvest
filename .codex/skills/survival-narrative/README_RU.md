# survival-narrative в Kvest

SKILL.md — предоставленный владельцем файл survival_narrative_SKILL.md, сохранённый без изменений.

## Применение

При проектировании, написании, продолжении и редактуре истории прочитать SKILL.md вместе с актуальным
CONTEXT.md и CHECKPOINT_WORKFLOW.md. Для обычной сборки, интерфейса и технических исправлений
без изменения истории или выбора навык не нужен.

Использовать существующие сохранения, STORY_STATE.md и игровые механики. Возможные ветви сохранять
как планы, фактически выбранное — как события. Сам навык не разрешает менять сохранения.
Прямые указания владельца, принятые правила Kvest и подтверждённые факты прохождения имеют приоритет.

Пункт о единственной проверке означает один объединённый проход по непротиворечивости.
После найденной ошибки и исправления нужно заново проверить затронутое.
Обязательные технические проверки проекта и самостоятельная литературная доработка сохраняются.
Цель следующих точек — стремиться к 9/10; интерес, темп, речь и напряжение также требуют авторской работы.
