# Kvest

Текстовый квест о постепенном зомби-апокалипсисе на севере Германии для двух игроков
(Android + iPhone). Офлайн-PWA, синхронизация на контрольных точках, совместные решения.

* Архитектура и план: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)
* Закрытая документация мира (игрокам не читать): `docs/hidden/`

```bash
npm install
npm test        # тесты движка
npm run dev     # локальный запуск
npm run build   # сборка в dist/
```

## Установка на телефон

Игра: **https://andrii-nehrii.github.io/Kvest/** (выкладывается автоматически при каждом обновлении).

* **Android (Chrome):** открыть ссылку → меню ⋮ → «Добавить на главный экран» / «Установить приложение».
* **iPhone (Safari):** открыть ссылку именно в Safari → кнопка «Поделиться» → «На экран „Домой“».

После первого открытия игра работает без интернета. Интернет нужен только на контрольных точках
(обмен кодами через мессенджер) и чтобы получить обновление.
