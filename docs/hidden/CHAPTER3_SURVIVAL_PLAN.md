# Закрыто для игроков — повседневные действия главы 3

Проблема: c6_start и новые сцены выключают universal; отдых утоляет жажду без расхода воды, а описанный ужин не связан с моментом еды. На базе уже существует суточный паёк: продукты списали утром, поэтому повторно выставлять счёт за него нельзя.

1. Вернуть нижнюю группу в текущем участке. Разделить доступность долгого отдыха, сна, кухни и выхода к машине по обстановке; короткие личные действия не исчезают вместе с ними.
2. Сохранять старые действия для воспроизведения старых кодов, новые ресурсные варианты выдавать под новыми id. Не возвращать игроков назад и не менять базу КТ5.
3. Личные продукты действительно расходуются, неполная единица даёт соответствующую долю сытости. Пустая бутылка остаётся и наполняется только из реальной воды.
4. На начало участка выделить небольшую личную долю дополнительной крупы/топлива из настоящего общего запаса, не больше половины доступного. Две независимые линии не должны обещать последнюю порцию дважды.
5. Принесённые десять литров появляются сразу после работы; при слиянии не создавать их повторно. Вода, принесённая вместо игрока, тоже учитывается, долг по работе остаётся.
6. Ужин использует личную уже оплаченную суточную порцию; можно съесть, взять с собой или отказаться. Передача порции другому лишает её владельца. Голод меняется при еде, а не при упоминании стола. Автоматический ужин в 19:00 не дублирует ручной.
7. Телефон: реальный заряд и кабель, расход пауэрбанка, связь по покрытию; стоянка с работающим мотором расходует топливо и время. Без источника питания заряд не появляется.
8. Проверить пустые запасы, дробные остатки, обе линии вместе, последовательности «готовка → еда», «выпить → пустая бутылка → наполнить», отдых/сон/батареи, старые префиксы, полный Vitest и мобильный интерфейс. Пользователю — без сюжета.

Проверка результата:

- «Ты остаёшься сыта» после отказа отдавать еду было неверным обещанием показателя до ужина. В новой реплике остаётся именно порция, не сытость.
- Отдых больше не обещает воду при пустом запасе: два результата по действительному наличию, расход пол-литра при питье.
- Прежнее «добавка из общего запаса» заменено отмеренными своими 250 г и 0,5 л, сама по себе готовка голод не снимает.
- «Взять с собой» и «поесть» разделены: предмет появляется только после упаковки, сытость — после употребления. Упакованную порцию можно отдать, получить повторно нельзя.
- Упоминание зарядки не заменяет источник: без кабеля/энергии кнопки нет, частичный остаток даёт частичную зарядку, машина расходует бензин и время.

Типы и полный Vitest: 391 passed, 2 штатно skipped. Все шесть e2e:quick прошли.
