## 1. Проект в пяти строках

Текстовый квест (TS/React/PWA) про зомби-апокалипсис на севере Германии для **одной пары**: A — он, B — она; каждый играет
на своём телефоне, на контрольных точках (КТ) журналы сливаются. Владелец — игрок: в чате **ни слова о сюжете**, отчёт —
«написана часть N, проверки прошли». Игра идёт по-настоящему: сыгранное не менять, новое — за `{ cp: N }`, эталоны и
`compat.test.ts` не трогать, версии не поднимать. В main не сливать (PR). Защищённые файлы — `AGENTS.md` п. 6.

## 3. Люди и голоса (коротко)

Хенрике — хозяйка хутора, приказы, решает она. Оле — её сын, ружьё, слово сквозь зубы. Павел — сезонник-поляк, тихо, о семье
под Щецином. Дениз — автомеханик, сухой юмор, держит слово; Керем — его младший брат, мягче. Окафор — медбрат, говорит как
в карте, «Перчатки — всегда». Мерле — соседка B, диабет, шутит, когда страшно. Ильзе и Герд — соседи A. Уве — инженер, «Хорошо»
как медаль; Биргит — кормит всех. Персонажи знают только то, что узнали в игре.

## 4. Где пара на самом деле и куда писать

Писать **только для мест, где эта пара ещё может оказаться**. Узнать (≈1 мин, сохранения не коммитить):
```bash
git fetch origin saves:refs/remotes/origin/saves && mkdir -p transcripts/pair
git show origin/saves:pairs/Uwz9uRin2OZVCugy/save-A.json > transcripts/pair/save-A.json
git show origin/saves:pairs/Uwz9uRin2OZVCugy/save-B.json > transcripts/pair/save-B.json
KVEST_PAIR=transcripts/pair npx vitest run src/content/pairpaths.test.ts     # → transcripts/pair-paths.txt
```
Список мест с долей прохождений: писать сверху вниз; мест, которых нет в списке, для пары не существует — их не трогать
(остаётся прежняя запасная версия). Пересчитывать после каждой пройденной парой КТ — список сужается.

## 5. Проверки (экономно)

По части: `npx tsc --noEmit`; `KVEST_QUALITY_FILES=chapter3/<часть>.ts npx vitest run src/content/quality.test.ts`;
одна стенограмма (`transcript.test.ts`, шапка файла) — прочитать один раз. Полный `npx vitest run`, `e2e` — не по частям,
их делает проверяющий перед слиянием.
