## 1. Проект в пяти строках

Текстовый квест (TS/React/PWA) про зомби-апокалипсис на севере Германии для **одной пары**: A — он, B — она; каждый играет
на своём телефоне, на контрольных точках (КТ) журналы сливаются. Владелец — игрок: в чате **ни слова о сюжете**, отчёт —
«написана часть N, проверки прошли». Игра идёт по-настоящему: сыгранное не менять, новое — за `{ cp: N }`, эталоны и
`compat.test.ts` не трогать, версии не поднимать. В main не сливать (PR). Защищённые файлы — `AGENTS.md` п. 6.

под Щецином. Дениз — автомеханик, сухой юмор, держит слово; Керем — его младший брат, мягче. Окафор — медбрат, говорит как

как медаль; Биргит — кормит всех. Персонажи знают только то, что узнали в игре.


(остаётся прежняя запасная версия). Пересчитывать после каждой пройденной парой КТ — список сужается.
