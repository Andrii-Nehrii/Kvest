## Оценка (5 — уровень глав 1–2)

Оценены новые части 1–2 (`farm5.ts`, `bflat5.ts`); остальная глава — прежняя версия (третий разбор).

| Пункт | Части 1–2 | Третий разбор |
|---|---|---|
| Структура | 4 | 4 |
| Объём и плотность | 3 | 4 |
| Напряжение и выборы | 3 | 3 |
| Решения на точках | — (не переделывались; прежние — 4) | 4 |
| Стиль и голоса | 4 | 3 |
| Техника | 4 | 3 |

Что хорошо: сцены написаны руками в стиле главы 2; люди говорят своими голосами (сухая шутка Дениза, приказы Хенрике,
Оле — одним словом); исход эпизода виден в тексте места; «под крышей» больше не улица; генераторов нет.

Почему не 5 — и это теперь ловит жёсткий стандарт (`quality.test.ts`, «прохождение как игрок»):
* **Объём**: участок 5 на хуторе — медиана 28 шагов (порог 30; в главах 1–2 — 40–59). Добирать не мелочами, а ситуациями
  с людьми: разговор в несколько заходов, просьба, тянущаяся до вечера, второй конфликт.
* **Напряжение**: медиана экранов с риском — **0** (порог 2). Ни одного действия с `risky`, проверкой навыка или травмой.
  Порез и спор из-за хлеба — хорошие бытовые конфликты, но опасности нет. Нужен хотя бы один момент «не по себе»
  с реальной ценой (опасность без боя — WRITING_GUIDE §3).
* **Мелочи** (из §8 третьего разбора): общий ночной текст `c5_start`; «Побыть рядом» с текстом «под одеялом» до «Лечь у печи».

## Жёсткий стандарт — что изменилось для тебя

Читать `CHAPTER_GUIDE.md` §9 и `AGENTS.md` п. 6. Коротко:
1. Перед работой — `git merge origin/main` (когда стандарт окажется в main). Защищённые файлы (`quality.test.ts`,
   `playtest.ts`, `transcript.test.ts`, `compat.test.ts`, `fixtures/`, `CHAPTER_GUIDE.md`, `WRITING_GUIDE.md`, `AGENTS.md`,
   `.github/`) в ветке не менять. Проверка PR берёт их из main; изменённые — автоматический провал.
   Твоя доработка `quality.test.ts` (проверка части по списку сцен) заменена встроенной: часть задаётся файлами —
   `KVEST_QUALITY_FILES=chapter3/farm5.ts npx vitest run src/content/quality.test.ts`.
2. Часть принимается, только если для её файла `quality.test.ts` зелёный целиком, **включая «прохождение как игрок»**.
   Сейчас: `farm5.ts` — красный (шаги 28 < 30, риск 0 < 2). Довести, потом следующая часть.
3. Сцены и тексты — только рукописные: id каждой сцены и каждый текст должны буквально стоять в исходнике.
   Циклы, `c${n}_…`, склейка текстов, JSON-дампы — провал теста.
4. Зелёный тест — минимум. Окончательная оценка — по стенограммам и таблице §8.3; цель — 5 по всем пунктам.
