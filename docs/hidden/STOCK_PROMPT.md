# Промт для большого запаса точек (составлен 14.11)

Владелец вставляет его в новый чат, когда решит начать. Промт не привязан к номерам точек: всё берётся из свежих данных.
Если владелец попросит «дай промт для запаса» — выдать ему блок ниже как есть.

```
Пишем большой запас точек наперёд — режим (Б) из CONTEXT.md: около 15 точек после последней написанной, каждая в полную
глубину под все ответы предыдущей точки, без проходов после нашей игры. Меня не будет около 20 дней, расписание нельзя.
Сюжет мне не пересказывай, вопросов не задавай — решай сам по документам, в конце отчёт одной-двумя строками.

1. Прочитай CLAUDE.md, CONTEXT.md (режимы письма, приоритеты моделей, последняя запись журнала), CHECKPOINT_WORKFLOW.md,
   TECHNIQUES.md. Возьми свежие сохранения пары, найди последнюю написанную точку и где мы сейчас. Всё, что мы уже
   выбрали, — канон; дальше всё неизвестное держи во всех вариантах.
2. Узнай свою модель (get_session). Сильная модель (Fable): общий план запаса и подробный план каждой точки, затем точки,
   отмеченные в плане ключевыми, затем сверка. Другая модель (Opus): точки по готовому плану, проверки, выкладка. Если плана
   ещё нет, а ты не Fable — составь его сам, так же подробно.
3. План — в docs/hidden: дуга на весь запас и набросок того, куда история идёт после него (открытые нити), чтобы потом
   можно было докинуть точки без шва. По каждой точке: время и места обеих линий, центральное событие, сцены, развилки внутри,
   вопросы КТ и все их исходы, отклики на прошлые решения (3–5 значимых мелких решений — где отзовутся), кто что знает,
   новые люди и предметы, еда/сон/связь, приёмы по жребию (node scripts/techniques.cjs N --write перед каждой точкой).
   Тяжёлые различия состояния сводить в заранее выбранных местах. Отметь 3–4 ключевые точки для сильной модели.
4. Пиши партиями по 2–3 точки. После каждой партии: tsc и весь vitest, тесты новых точек в point-тесте, стенограммы обеих
   линий от наших сохранений по всем исходам прошлой КТ (прочитать как игрок), сохранения пары повторяются без обрезки,
   браузер (два телефона), затем коммит и выкладка по CLAUDE.md — чтобы у нас всегда был готовый запас. Партию не
   выкладывай с падающими проверками.
5. Не останавливайся после плана или одной партии: продолжай, пока есть лимит. Перед концом сессии запиши в CONTEXT.md, где
   остановился и что дальше, чтобы следующий чат продолжил по фразе «продолжай запас».
6. Когда запас дописан: прогон случайных игроков через весь запас на многих сидах и всех ответах КТ — нигде нет тупика,
   выбывание и спасение работают, миры на точках сходятся. Обнови STORY_STATE, ARCHITECTURE §14, «Следующий шаг» в CLAUDE.md.
```

Короткое продолжение для следующих чатов (той же или другой моделью): `продолжай запас`.
