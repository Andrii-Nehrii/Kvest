# Промт для большого запаса точек (составлен 14.11)

Владелец вставляет его в новый чат, когда решит начать. Промт не привязан к номерам точек: всё берётся из свежих данных.
Если владелец попросит «дай промт для запаса» — выдать ему блок ниже как есть.

```
Пишем большой запас точек наперёд: подробный план на 15 точек после последней написанной и короткий набросок ещё на 5–8
(куда идёт история, открытые нити) — чтобы потом докинуть точки без шва. Меня не будет около 20 дней, расписание нельзя.
Сюжет мне не пересказывай, вопросов не задавай — решай сам по документам, отчёт одной-двумя строками.

Как договорились (CONTEXT.md, «Режимы письма»): режим (Б) — каждая точка в полную глубину под ВСЕ ответы предыдущей КТ,
без проходов после нашей игры. Отдельные сочетания ответов не пишутся: развилки идут через состояние мира и память людей
(кто рядом, что есть, кто доверяет, что знают), тяжёлые различия сводятся в заранее выбранных местах. В каждой точке —
3–5 значимых мелких решений из прошлого с заранее прописанным откликом. Качество не ниже нынешних точек: формат, объём
(20+ минут каждому), речь, механики и приёмка — по CHECKPOINT_WORKFLOW.md, приёмы — по жребию TECHNIQUES.md.
Риск в выборах — как решено в CONTEXT.md: читается из текста, у осторожного варианта своя цена, у рискованного видимая награда.

1. Прочитай CLAUDE.md, CONTEXT.md (режимы, приоритеты моделей, журнал), CHECKPOINT_WORKFLOW.md, TECHNIQUES.md.
   Возьми свежие сохранения пары, найди последнюю написанную точку и где мы сейчас. Сыгранное — канон.
2. Узнай свою модель (get_session). Fable: план, затем точки, отмеченные в плане ключевыми, затем сверка запаса.
   Opus: точки по готовому плану. Если плана нет, а ты не Fable — составь его сам, так же подробно.
3. План — в docs/hidden. По каждой точке: время и места обеих линий, центральное событие, сцены, развилки внутри,
   вопросы КТ и все исходы, отклики на прошлое, кто что знает, новые люди и предметы, еда/сон/связь, приёмы
   (node scripts/techniques.cjs N --write). Отметь 3–4 ключевые точки для Fable.
4. Каждую точку после письма прочитай стенограммами обеих линий по всем исходам прошлой КТ и поправь — это часть письма.
   Тяжёлые проверки (весь vitest, браузер с двумя телефонами, повтор наших сохранений без обрезки) и выкладку — один раз
   в конце каждого чата, а не после каждой точки: так у нас не кончится готовое, пока ты пишешь дальше. С падающими
   проверками не выкладывать.
5. Не останавливайся после плана или одной точки: продолжай, пока есть лимит. Перед концом чата запиши в CONTEXT.md,
   где остановился, чтобы следующий чат продолжил по фразе «продолжай запас».
6. Когда запас дописан: прогон случайных игроков через весь запас на многих сидах и всех ответах КТ — нигде нет тупика,
   выбывание и спасение работают, миры сходятся. Обнови STORY_STATE, ARCHITECTURE §14, «Следующий шаг» в CLAUDE.md.
```

Короткое продолжение для следующих чатов (той же или другой моделью): `продолжай запас`.
