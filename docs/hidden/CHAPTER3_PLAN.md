## Матрица мест (каждая строка проверяется через все четыре участка)

- Хутор: вместе / один; ночёвка в доме или сарае. Полноценные погреб, колодец, калитка, работа, два эпизода каждого участка.
- Курятник: оба / один / партнёр в доме. Собственные эпизоды через дверь; выпуск после суток без видимого риска, новый карантин в день прибытия не снимать.
- Квартира A: хозяин / пара; закрытый доступ → временное укрытие. Лестница с живым Гердом закрывает свободное перемещение.
- Квартира B: хозяйка / пара; утраченная квартира → укрытие. Окафор и Свенья — по реальному состоянию, не обязательно живые.
- Мастерская: с ключами / Дениз рядом; иначе за воротами. Склад отдельно от жилой части.
- Ahrensburg: дом Тиссенов, Мерле по своему местонахождению. Электричество и инсулин не обещать при отсутствии.
- Север: спортзал, очередь и дежурства DRK; не превращать приезжих в командиров.
- Messe / наблюдение: разные помещения, 48 часов от регистрации; 13.11 вспышка приводит к объективному выходу во двор.
- Улица / машина / чужой подъезд: место сохраняется, без телепорта в другой регион. Два собственных эпизода на каждом участке, запас и ночлег не гарантированы.

## События, плотность и стиль

В каждом участке у каждого места два эпизода с interrupt и окнами времени, несколько последовательных наблюдений / разговоров / решений с ценой. Выход из эпизода возможен раньше, но исход запоминается; пропущенный срок меняет мир без игрока. Рутинные дела сопровождаются местными людьми и имеют последствия. Ночные / утренние / дневные / вечерние блоки у каждого места свои.
12.11 и 13.11 — отдельные наборы сцен и действий; никакого fourthDay и абстрактного c3_focus. Общие функции только собирают данные, не пишут одинаковую прозу. Ориентир — 2000 строк данных на день и 50–70 осмысленных решений при обычном прохождении, без принудительного количества пустых нажатий. Быстро уйти на точку можно; это не ориентир полноты.

## Точки

КТ 5: дневная вылазка за водой, соседний обмен, отдать закрытую часть запаса, остаться. Для хутора — обмен картошки на шланг/крепёж; для города и юга разные раздачи. Отдача меняет общий запас сразу, вылазка — маршрут следующего участка.
КТ 6: остаться в текущем месте; пустить проверенного гостя (хутор, согласие Хенрике, дополнительный рот), предоставить только отдельную ночёвку; выдать еду и отказать в ночлеге; переехать на доступный хутор/север (объективная география). Тяжёлый размен: тепло для незнакомого человека против запаса своих.
КТ 7: ближайшая раздача воды / соседний обмен при доступном запасе / передать закрытую пачку / остаться. Выход из зала при вспышке обязателен до точки, а не обещан как поздний вариант. КТ 8: ночёвка и распределение оставшегося запаса, а не «приоритет». При споре порознь никто не уезжает автоматически.
Заметки: конкретно про место, увиденные последствия и известные факты. Встречу и сведения получают оба, порядок A→B не должен скрывать заметку B.
