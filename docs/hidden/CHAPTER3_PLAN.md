В 12:00 радио сообщает о закрытии пункта. Не вводить универсальное отключение сетей: электричество и вода читаются из мира.

## Совместные решения

КТ 5: supply/repair/rest → w.c3_focus. repair выполним только если оба на одной базе и есть доступный проект; supply всегда, rest — default. Порознь разные ответы → rest. Дефицит базы при споре → supply, сильная усталость → rest, иначе repair при выполнимости. Заметки: встреча/разлука по группам мест и личным меткам, обмен только известными фактами при встрече/связи; проверка риска и выпуск из курятника только со следующего участка. КТ 6: settle/watch/search → w.c3_next; settle только вместе на доступном месте; порознь спор → watch, default watch. Следующая сцена c7_start — честный конец доступной части.

## Самопроверка после реализации

- Живые NPC: все взаимодействия и признаки присутствия новых сцен используют alive; болезнь Окафора — agenda, работает вдали от игроков; отдельная регрессия для погибшего.
- Транспорт: сначала подойти к машине, затем drive; линия B не тратит бензин. Южные местные пути имеют пешую альтернативу. Без транспорта городской кордон не пересекается. После автобуса машина остаётся на южном берегу. Проверены оба телефона и недостаток топлива.
- Квартиры: хозяин либо вместе с хозяином, не flat_lost; свободно ходящая обращённая закрывает вход. В запертую мастерскую не попадают без ключей.
- Время: дела имеют окна, тексты отдельно до рассвета / день / вечер. Новые дорожные расстояния: местные 4–7 км, Harburg +20 км, город +38 км. Коридор учитывает открытие, очередь и закрытие. Наблюдение нельзя снять общим дорожным решением. Новый карантин на хуторе не снимается в день прибытия (остаётся для следующей проверки).
- Два телефона: общую добычу, обмен и ресурсы ведёт хозяин линии; второй помогает. На КТ встречу и обмен знаниями получает каждый. Проекты квартир разделены по адресам.
- При проверке обнаружено: одинаковые изменения delta и одинаковый расход одной стопки преждевременно считались одним изменением. Исправлено в checkpoint.ts только при base.checkpoint >= 4 и двух независимых ведущих. Одна линия ведущего не удваивается. Регрессии проверяют и старый участок, и новый. До КТ 4 расчёт сохранён.
- Все хабы имеют ожидание, местный выход и последнюю кнопку КТ. Из наблюдения после вспышки остаётся объективный выход во двор, на обеих линиях одинаково. Приоритет КТ 5 открывает отдельные дополнительные действия; КТ 6 сохраняет намерение для следующей главы.
- Все новые события / планы NPC за cp:4, гость четвёртого дня за cp:5, базы from:4. Старые эталоны и версии не менялись.
- Типы, линтер текста, матрица стартов, все пары ответов, совместная работа и расход, настоящие сохранения, общие случайные прохождения и главная линия проверяются тестами. Результаты окончательного браузерного прогона — в PR без сюжетных подробностей.
